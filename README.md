# RECETAS-CLINICA

Sistema web para la gestión de recetas y órdenes de laboratorio del consultorio.

## Módulos
- Recetas
- Órdenes de laboratorio
- Productos y estudios guardados
- Paquetes y combinaciones
- Registro de documentos emitidos
- Edición e impresión

## Tecnologías
- GitHub
- Supabase
- Vercel
